# Anamika Singh | Portfolio

Professional portfolio website for Anamika Singh, a MERN Stack Developer based in Bengaluru, India.

The site presents her experience, technical skills, featured projects, certifications, development process, and contact information in a polished, responsive single-page experience.

## Highlights

- Premium dark visual design with responsive layouts
- Hero section with resume download and contact actions
- Technical skills grouped by frontend, backend, databases, languages, cloud, and testing
- Professional experience timeline
- Featured project showcase with technology tags and live links
- Certifications and development process sections
- Direct email, GitHub, and LinkedIn contact links
- Built for fast production deployment with Vite and Vinext

## Tech Stack

- React 19
- TypeScript
- Vite
- Vinext
- Tailwind CSS 4
- Lucide React
- Next.js-compatible app structure
- ESLint

## Project Structure

```text
app/
  page.tsx          # Portfolio page and content
  globals.css       # Global theme and responsive styling
  layout.tsx        # Metadata and application shell
components/ui/      # Reusable UI components
public/             # Static assets and downloadable files
tests/              # Build and rendered HTML tests
```

## Getting Started

### Prerequisites

- Node.js `>=22.13.0`
- npm

### Installation

```bash
npm install
```

### Run locally

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production build

```bash
npm run build
```

### Run tests

```bash
npm test
```

## Customization

Update the portfolio content in [app/page.tsx](app/page.tsx), including:

- About information
- Skills and technologies
- Professional experience
- Project descriptions and URLs
- Certifications
- Contact and social links

Update the visual system in [app/globals.css](app/globals.css). The main colors, borders, shadows, spacing, and responsive breakpoints are defined there.

Place the downloadable resume at:

```text
public/Anamika_Singh_Resume.pdf
```

## Deployment

The project can be deployed to any platform that supports Vite or Vinext applications. Before deploying:

1. Add the production portfolio URL to this README.
2. Confirm the resume exists in the `public/` directory.
3. Replace placeholder project URLs with live project links.
4. Run `npm run build` to verify the production output.
